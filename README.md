# 1순위 실용

할 일 목록 대신 **지금 할 일 딱 하나**만 보여 주는 안드로이드 앱입니다.
내가 정한 가치 순위(건강 · 가족 · 일 …), 지금 시간대, 내 상태, 일정, 날씨를 보고 하나를 골라 주고, 완료하면 바로 다음 걸 추천합니다.

![화면 미리보기](docs/preview.png)

## 다운로드

**[priority-practical-v1.5.apk 받기](https://github.com/jinsoo69/priority-practical/raw/main/priority-practical-v1.5.apk)** (약 0.5MB · 안드로이드 8.0 이상)

1. 위 링크를 휴대폰에서 누르면 APK가 받아집니다.
2. 받은 파일을 누르고, 처음이면 ‘출처를 알 수 없는 앱 설치’를 허용합니다.
3. 플레이스토어 앱이 아니라서 Play 프로텍트 경고가 뜰 수 있습니다. 찝찝하면 설치하지 않아도 됩니다.

## 하는 일

- **지금 딱 하나** · 가치 순위 · 시간대 · 상태(에너지, 여유 시간, 있는 곳)를 보고 할 일 하나만 띄웁니다. 완료하면 바로 다음 추천이 뜹니다.
- **작게라도** · 기운이 없거나 시간이 부족하면 작은 버전으로 바꿔 권합니다. 예: 30분 걷기 → 5분 걷기.
- **시간대 반영** · 아침·점심처럼 때가 정해진 일은 시간이 지나면 권하지 않고, 자려던 시각이 지나면 자는 것부터 권합니다.
- **날씨·공기 반영** · 비, 미세먼지 나쁨, 폭염이면 야외 행동을 실내 버전으로 바꾸고, 나가기 전 우산·마스크를 챙기게 합니다. 공휴일도 반영합니다.
- **일정표** · 일정 제목으로 중요도(필수·중요·보통·선택)를 스스로 판단하고, 출발 준비 시각을 알려 주며, 남은 할 일을 빈 시간에 자동으로 배치합니다.
- **추천 근거** · 왜 이걸 골랐는지 단계 · 우선순위 · 상태 · 일정 · 환경 순서로 보여 줍니다.
- **기록** · 최근 7일 실천 점수, 1순위 연속 기록, 가치별 실천율, 수면·운동 같은 실제 수치 기록.

## 개인정보와 권한

- 회원가입, 광고, 분석 도구가 없습니다. 기록과 일정은 휴대폰 안에만 저장됩니다.
- 인터넷은 날씨·미세먼지를 받을 때만 씁니다. 이때 밖으로 나가는 정보는 고른 지역의 좌표뿐입니다([Open-Meteo](https://open-meteo.com/)). 설정에서 끌 수 있습니다.
- 권한: 인터넷(날씨), 알림(행동·일정 알림), 부팅 후 알림 다시 등록, 정확한 시각 알람.

## 참고

- 수치 기준(수면 7시간, 주 150분 운동, 미세먼지 등급 등)은 공개된 권고 기준을 요약한 것이고, 점수와 추천은 앱 자체 규칙입니다. 건강 효과를 보장하지 않습니다.
- 미세먼지는 약 45km 격자 예보 값이라 동네 측정소 값과 다를 수 있습니다.
- 개인이 만든 앱이라 버그가 있을 수 있습니다. 이슈로 알려 주세요.
